Why PRless

Give AI review what human review already has

Comments pinned to exact lines — not prose you type into a chat box and hope the agent maps back to your code.

GitHub-style diff view

Working tree, staged, or branch compare — split or unified, with full syntax highlighting.

Inline · range · file comments

Click a gutter, drag across line numbers, or comment on a whole file. Resolve, reopen, delete.

Durable, drift-aware

Comments are anchored with surrounding context, so they survive as the agent rewrites your code — and flag when it drifts.

One-click AI handoff

Copies an agent-ready prompt to your clipboard and writes .prless/review.md. Export everything, or just the comments you tick.

Built for big diffs

File search, single-file view, “commented only” & “hide generated” filters, .prlessignore, and path scoping.

Keyboard-driven & themed

Shortcuts for everything (rebindable), 12+ syntax themes, light & dark — preferences persist.

The loop

From diff to applied fix — on your machine

No remote, no PR, no MCP. The handoff is a plain file plus a clipboard copy, so it works with any agent.

1

Open a diff

prless open . (or the VS Code command) renders your uncommitted changes.

2

Comment inline

Pin notes to exact lines, just like reviewing a GitHub pull request.

3

Export for AI

Open comments are grouped by file into .prless/review.md and copied to your clipboard.

4

Agent applies it

Paste into Claude Code, Codex, or Cursor. Each comment becomes a change. Then re-review.

Two ways to run it

In your browser, or right in your editor

Same review engine, same .prless/ handoff — pick whichever fits your flow.

CLI Browser review

A tiny local server opens your diff in the browser. Zero config.

# install once

# review the current repo
$ cd your-project
$ prless open .
